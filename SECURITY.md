# 🔒 Security Policy

## 🛡️ Versions supportées

Ces projets sont des outils domotiques personnels — il n'y a pas
de versioning strict. Le code sur la branche `main` est toujours
la version la plus à jour et la seule maintenue.

| Branche | Supportée |
|---|---|
| `main` | ✅ Oui |
| Autres | ❌ Non |

---

Tu as trouvé une faille de sécurité ? Merci de **ne pas ouvrir
une Issue publique** — contacte-moi directement :

- 📧 alexandre.chretien60@gmail.com
- 💻 [alweddle.github.io](https://alweddle.github.io)

## ⚠️ Avertissement important

Ces projets contiennent des configurations spécifiques à mon
installation (IDs Jeedom, tokens...). Si tu forkes ce repo,
**ne publie jamais** tes propres tokens ou identifiants dans
le code source.
